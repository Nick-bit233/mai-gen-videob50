# 查分器 OAuth 导入

舞萌的导入流程为：用户授权 → 读取全部成绩 → 选择 B50 或 AP B50 → 保存本地存档。
水鱼、落雪均使用公开客户端的授权码 + PKCE，不再使用用户名、好友码、个人 API 密钥或开发者 Token 查分。

## 使用

1. 在“获取和管理分表数据”中设置本地用户名。这只是存档标签，不必等于查分器用户名。
2. 打开“创建新存档”，选择水鱼或落雪，点击“授权并获取全部成绩”。
3. 点击授权链接，在**运行本程序的同一台电脑**的浏览器中登录查分器并同意读取成绩。
4. 授权页面完成后返回程序，全部成绩会自动加载。
5. 默认选择 **B50**；也可选择 **AP B50**。确认预览后点击“将所选分表保存为新存档”。

B50 按旧曲 35、新曲 15 分组，分别按单曲 Rating、定数、达成率降序排列。同分时保持来源顺序。AP B50 不分新旧版本，只保留 `ap` / `app`（AP / AP+），再排序取最多 50 个不同谱面；不足 50 个时保存实际数量，没有 AP 时不创建空存档。宴会场成绩不参与这两种筛选。落雪 Rating 先向下取整。

水鱼沿用 SaaS 的全部成绩与新版本分组查询，核对服务端返回的筛选条件后分类。落雪沿用按**谱面版本**分类的规则，排除明确停用的谱面；当前曲库无法识别的成绩只允许通过有限历史曲库查询确认已移除，无法确认则报错。不会把缺失版本的高分曲目猜成旧曲或静默跳过。

中二节奏同样改为 OAuth 获取全部成绩，保留旧曲 B30、新曲 N20；不提供舞萌的 AP B50 选项。文件导入和历史存档继续可用。

## OAuth应用登记

桌面程序需单独登记**公开客户端 / 分发给用户各自部署**的应用。

开发者已经在当前仓库配置了一份默认公开客户端应用ID，通常使用者无需修改。如果需要更改为自行分发的应用，请参考下面的内容。

| 查分器 | 默认登记回调 | 读取权限 |
| --- | --- | --- |
| 水鱼 | `http://127.0.0.1:8766/callback` | 舞萌 `prober.records.read`；中二 `chunithm.records.read` |
| 落雪 | `http://127.0.0.1:8767/callback` | `read_player` |

水鱼允许 IP 回环地址动态端口；落雪回调须与登记值一致。两家的授权请求都带随机 state 和 PKCE S256。仅申请成绩读取权限，不申请上传或修改成绩权限。

维护者将公开的 `client_id` 填入 `static/oauth_public_clients.json`，该文件会随应用包分发。当前已提供默认客户端；自行分发时，请先完成应用登记，再替换对应配置。每位使用者无需登记自己的应用，也无需填写个人 Token。

本地开发可在项目根目录新建已忽略的 `oauth_config.json` 覆盖分发配置：

```json
{
  "fish": {"client_id": "水鱼公开客户端ID", "port": 8766},
  "lxns": {"client_id": "落雪公开客户端ID", "port": 8767}
}
```

也可设置环境变量 `MAIGEN_FISH_OAUTH_CLIENT_ID` / `MAIGEN_LXNS_OAUTH_CLIENT_ID`，可选 `MAIGEN_FISH_OAUTH_PORT` / `MAIGEN_LXNS_OAUTH_PORT`。优先级为环境变量、本地配置、随包配置。页面的“OAuth 应用配置”允许临时覆盖当前会话。配置只接受 `client_id`、`port`。

## 生命周期与故障处理

- 回调只监听 `127.0.0.1`，不支持从另一台设备访问本程序后直接回调。授权完成、取消或等待 10 分钟后关闭监听。
- 收到回调立即兑换授权码并读取全部成绩，避免水鱼短时授权码过期。state 必须匹配，授权码只处理一次。
- 令牌仅用于本次请求，不保存 access token 或 refresh token；本地原始成绩缓存与存档均不包含 OAuth 凭据。旧 `lxns_credentials.json` 不再读取或使用。
- 在同一会话中切换 B50 / AP B50 使用已获取的成绩快照，不重新授权。刷新成绩或切换查分器账号需重新授权；切换本地用户名或游戏会丢弃对应旧会话。
- 授权拒绝、超时、网络错误、权限不足、返回结构异常均显示错误。重试需新建授权流程，不退回旧查分渠道。
- 端口占用时结束另一个授权流程或更换端口，并核对查分器登记的回调。
- 若选中曲目尚未匹配本地曲库，请先更新元数据，再用当前快照重试保存。

第三方查分器接口文档参考：[落雪 OAuth 指南](https://maimai.lxns.net/docs/oauth-guide)、[水鱼 OAuth 迁移指南](https://maimai.diving-fish.com/manual/docs/developer/oauth-migration/)、[水鱼 OAuth 接口](https://maimai.diving-fish.com/manual/docs/developer/oauth-api-document/)。
