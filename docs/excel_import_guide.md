# Excel 自定义存档导入

在“编辑数据/创建自定义数据”中先选择用户名和自定义存档，再展开“从 Excel 批量导入自定义记录”。

1. 下载当前游戏的样本，数据填写在 `Sheet1`。首行是表头，一行是一条谱面或记录；请删除样本行后填入自己的数据。
2. 上传 `.xlsx`，选择工作表并检查列映射。标准字段及中英文别名可以识别，相似表头会提供候选。每个字段只对应一列，其他列选择“忽略”。
3. 如果曲绘列使用相对路径，填写曲绘根目录。绝对路径指向运行应用的电脑；浏览器上传 Excel 不会提供原文件所在目录。
4. 点击“预览导入结果”，检查成绩、Rating、默认值和曲绘。缺失字段使用预览中显示的默认值；无效数值会显示原因。需要修正时更新表格并重新上传或调整映射。
5. 选择追加或替换草稿，确认预览后导入。程序切换到手动填写模式，点击“提交存档修改”，才将谱面、成绩及曲绘保存到数据库。“存档类型”标签页中的“提交修改”只用于存档类型配置。

舞萌达成率填写 `100.5` 表示 `100.5%`，也可使用 Excel 百分比格式或文字 `100.5%`。中二成绩填写整数分数，例如 `1009000`。`difficulty` 表示谱面定数，`level_index` 表示 BASIC/ADVANCED/EXPERT/MASTER/RE:MASTER 或 ULTIMA，请勿混淆。

显式填写 Rating 时保留填写值，未填写时使用有效定数和成绩计算；定数可填写 `?` 等文字，无法计算的 Rating 使用 `0`。FC/FS 支持现有游戏选项和常用加号写法。没有成绩时不会补为理论值。

曲绘支持程序可解码的本地图片。保存时裁成正方形并缩放为 400×400，保存后不再依赖原文件。文件缺失或损坏时记录仍可导入，曲绘留空并提示。导入限制为 10 MiB、5000 条记录、64 列；曲绘单文件最多 20 MiB。

公式只读取工作簿中已保存的计算结果。没有缓存时，请先在 Excel 中计算并另存为数值；程序不会运行公式或宏。完全自定义谱面获得独立 ID，不覆盖官方谱面或其他存档。歌曲 ID 列作为来源参考保留。

`video_path` 可填写本地视频路径，`video_source` 可填写 BV 号或 Bilibili 链接，`source_pid` 填写从 1 开始的分 P。未填写时继续使用舞萌元数据匹配或中二原有搜索流程。
